**About the Game:**
Tic-Tac-Toe is a classic two-player game played on a 3×3 grid. Players take turns marking X and O. The first player to get three marks in a row, column, or diagonal wins the game.

### 2. Stone Paper Scissors Game

A simple, interactive, and fun Stone Paper Scissors game developed using HTML, CSS, and JavaScript.

**About the Game:**

Stone Paper Scissors is a classic hand game played between a user and a computer. The user selects one of three options: Stone, Paper, or Scissors. The computer randomly generates its choice, and the winner is determined based on the game rules.

**Features:**

- Three interactive choices: Stone, Paper, and Scissors.
- Computer generates random choices automatically.
- Real-time score tracking for both the user and computer.
- Automatic winner and loser detection.
- Draw detection when both choices are the same.
- Interactive messages showing the game results.
- Simple and user-friendly interface.
- Responsive design for different screen sizes.
